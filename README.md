# R9-Security_ServerMonitor
Web UI Server monitor, can be quickly deployed for hosting and nodes with adjustable reporting times. Monitors server or device usage on (CPU, RAM, DISK, NETWORK, ACTIVE CONNECTOINS, ACTIVE SERVICES, UPTIME) and MORE!
Make sure to create your payload file, its called "Agent Setup Script" in the WEB UI Adjust the values to get a proper connection
If you're running localhost make sure to change it to localhost instead of "0.0.0.0" unless you're trying to accept incoming connections 
HTTP(pull) works better for me, adjust as needed.
